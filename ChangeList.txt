Version 1.9.0
- Keep map view on resize: the map scale stays right when the Tactical Display is closed (a desktop without the map) and opened again at another size.
- Unit Status: the Reference tab was empty in the newer game build (its new Supplies tab has the same tab number); the Reference tab has a number of its own now.
- Unit Status: remembers the tab for each unit (contact) and opens it again when the unit is selected again, if available (option).
- Unit Status: the Reference tab is shown for missiles and torpedoes too (their weapon page).
- Unit Status: the Reference tab is also available for a contact of another side once its type is determined (the Unit Reference of that type; the Track State tab stays, before the Reference tab, which is always the last).
- Menu and loading backgrounds: the replacement is installed at game start (the game's pictures were visible for 1-2 s). New option "Real photos as backgrounds" (this mod's own pictures, default on); when off and no other mod brings pictures, the game's own are shown whatever "Background pictures" says.
- Desktop mode, new option "Other monitors for windows" (on by default): every other monitor works like the main one for windows (Monitor in the window's menu, remembered per desktop). The game's own second-monitor map and World View monitor are then not used. The backdrop picture is on them too; the Tactical Display and World View can be placed there as well.
- Main menu background: new option, a slideshow of the background pictures (default, 15 s a picture; the video is not loaded then) or the game's video.
- Event Log: the first click on a contact link only selects it, a repeated click on the same link also centres the Tactical Display on it.
- Window menu: "Text outline" is replaced by "Text contrast" - grey texts become pure white or black with a halo, readable at high transparency; switches on by itself when the opacity goes below 50% (off above it), you can change it.
- Desktop mode with the game's own World View monitor: the 3D view is no longer paused, the mouse works on that monitor.
- Unit Reference: a "Source" drop-down next to the search box - tick the sources (base game and mods) whose units the tree shows (any number, at least one).
- Sea Power 0.9.0: no "incompatible mod" warning at start; the mission timer moves together with the dragged time panel; Dismiss Damaged leaves the flagship alone.
- Desktop mode, other monitors: a lighter camera on them (no G-buffer or depth texture of the game's rendering path).

Version 1.8.2
- Unit Status, Damage Control: the damage lists of the sections (flooding, fires, damaged systems) scroll with the mouse wheel (option).
- Window opacity: the selection / hover colours of list, tree, tab and button items follow their state again and stay dimmed (the unit type tab of the Unit Reference that was selected before stayed red).

Version 1.8.1
- Binoculars at the maximum magnification start with the normal view instead of the night / thermal filter (by day only, optional); moved here from Alternative Special Effects.
- Unit Reference: a Propulsion cell (engine type and power) for ships and submarines, after Max Speed.
- The gear of the World View window offers the settings of this mod and of Alternative Special Effects.
- Windows of other mods drawn with Unity IMGUI (Camera Offset) can be grabbed and dragged over the game's windows.
- Moving or resizing any window over the 3D view no longer turns the camera (the game's own check is wrong at screen heights other than 1080).

Version 1.8.0
- The mod is now called Alternative Game Interface (the Workshop item is the same; settings and saved windows are carried over).
- New entry "Game Interface" in the main menu (under Mod Manager) and in the pause menu (under Options): the settings window without opening a game window first. With several of the author's mods installed the entry becomes "Alternative Mods" with a list.
- Event Log: every track number is a link (the game links only some; option "All contacts in the log are links"). A click on a contact or unit link also centres the Tactical Display on it (option "Center map on clicked contact"). New "Event Log" tab in the settings window.
- Menu backgrounds: the option "Backgrounds from mods only" became a choice "Background pictures": mods only / mixed / game only. The mod's own folder ui/backgrounds is ready for its pictures.
- Unit Status, Damage Control: with a small window the section lists no longer run past the bottom edge of the window.
- The gear and the arrow of the window look menu sit among the buttons of the title bar and no longer lie over buttons that other mods add there (for example Topography on the map).
- Desktop mode, optical view: the binocular frame and interface fit the World View window (enlarged up to 30%), mouse camera control works over the picture, Backspace gives a full-screen binocular view, resizing a window over the World View no longer turns the camera.
- Ship binoculars can be lowered below the horizon (option "Ship binoculars below the horizon", 10 degrees by default).
