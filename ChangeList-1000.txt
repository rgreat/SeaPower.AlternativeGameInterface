Version 1.7.0 - the mod is now Alternative Game Interface (settings are carried over).

The 3D view is rendered pixel for pixel into the World View window; backdrop picture behind the windows (replaceable); The minimap key (Tab) switches 2-5 desktops, remembered; "Desktops" settings page; World View on/off key; Backspace: 3D view fullscreen; compass tape inside the window.
- Window look menu: opacity, scale, level (map, 3D: Bottom).
- Docked windows can be resized from every edge.
- Draggable time panel, kept per desktop.
- Keep map view on resize (option).
- Unit Status: Track State tab.
- Event Log: all tracks are links; a click centres the map.
- Campaign: Upgrade ship, dismiss damaged, loadouts by date.
- News window: gear, frame, position.
- Backgrounds from mods and Strict loadouts fixes.
- AddWindowKey (F12) removed.
